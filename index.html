Daftar Pintasan Keyboard (Shortcuts)
Spasi : Putar / Jeda
. / , : Maju / Mundur 1 Frame
← / → : Lompat 1 Detik
I : Set Batas Mulai (START)
O : Set Batas Akhir (END)
C / K : Pecah Klip / Anotasi (Split)
X : Potong Video (Cut)
V : Alat Seleksi
H / Spasi + Drag : Alat Tangan (Pan Kanvas)
R : Alat Kotak
O : Alat Elips / Lingkaran
A : Alat Panah
D : Alat Highlighter (Stabilo)
T : Alat Teks
N : Alat Nomor Langkah (1, 2, 3...)
B : Alat Sensor (Blur / Pixel / Hitam)
S : Alat Spotlight
M : Alat Kaca Pembesar Loupe
Scroll Mouse di Timeline : Geser Horizontal
Ctrl + Scroll di Timeline : Zoom Skala Timeline
Ctrl + C : Salin Snapshot ke Clipboard
Ctrl + S : Simpan Snapshot PNG
Ctrl + E : Ekspor Video / Paket ZIP
Ctrl + Z / Y : Undo / Redo
Delete : Hapus Anotasi Terpilih
Ctrl + Scroll Kanvas : Zoom In / Out Viewport
